Sundorika-beauty

Sundorika is a beauty and cosmetic blogging website designed to provide useful information about different cosmetic brands, beauty products, and skincare. The main purpose of this website is to help users learn about cosmetic products and explore beauty-related articles in one place. The website allows visitors to read blog posts about various cosmetic brands and beauty topics. Users can view a short description of each blog post and click the “Read More” button to read the full article on a separate page. Registered users can log in or sign up to access features for writing, publishing, and editing blog posts. Sundorika is developed using HTML, CSS, JavaScript, and Firebase. Firebase Authentication is used for user login and registration, while Cloud Firestore is used to store blog posts and related information. Overall, Sundorika aims to create a simple, user-friendly, and responsive platform where beauty lovers can explore cosmetic brands, gain knowledge about beauty products, and share their thoughts through blog articles.
